### 0.1 推荐

| 项 | 内容 | 一句话说清 |
|---|---|---|
| **主攻** | **Claim A：把「测量可信度」做成系统的一等输出 —— 每个测量量带数值不确定度，并据此判定结论是否被数据支持** | 创新点是**用不确定度传播反向算出「这次测量在原理上能支持什么结论」**，不是多测一个量。开源分析栈（sigrok / ngscopeclient）在检索能力受限下未发现测量有效性/不确定度概念（附录 A.4）；GUM 的通用传播库确实存在（`uncertainty-toolbox` / `UQpy` / `OpenTURNS`），缺的是把它们接到示波器测量上的那一段。**「不可信时输出第三值」只是这条输出的形态之一，不是创新点本身。** |
| **备选** | **Claim B：测量可信度层的完整 GUM 化（JCGM 100/101/106 全量落地）** | 同一件事做到标准级完备（蒙特卡洛传播 + 护带判定规则 + 消费者/生产者风险）。**它是 Claim A 的完备版，不是另一个方向**；只能当备选，因为它需要真实实现与真实数据（§5.3）。 |

Claim A 是 Claim B 的可提交子集。对外承诺的边界必须画清楚：**不要承诺产不出的指标**。

### 0.2 三条必须同时成立的前提（任一条不成立，主攻方向要换）

1. **不把卖点押在 MCP 本身上**。arXiv API 实测（2026-10-10，两名执行者独立复现，四个数一致）：
   `abs:"Model Context Protocol"` 命中 **586** 篇，`abs:"oscilloscope" AND abs:"language model"` 命中 **0** 篇。
   ⇒「用 MCP 暴露仪器」在 2026 已无新颖度。**但「示波器 × 语言模型」这一格也不是空的**：
   GitHub 上至少有 `MagnusJohansson/siglent-sds-mcp`（面向 Siglent 示波器）与
   `Netlist-Studio/scope-mcp`（经以太网控制 Keysight/Agilent 示波器），检索时均返回 HTTP 200
   （本会话未能二次核对，见附录 A.4）。
   ⇒ **正确口径**：不是「没人做 MCP + 示波器」，而是「**做了也没做测量不确定度这一层**」。
   MCP 只是通道，**卖点必须是「结论可信」**；第三值是这种可信度的输出形态，不是卖点本身。
2. **换板无关性只承诺「零硬编码能力声明」，不承诺「零人工」**。见 §3.2。
3. **不承诺上升时间结果**。`Ts ≈ 1.167 µs`，亚微秒边沿在单次 ADC 采集里**没有中间样点**，
   信息不在数据里，插值补不回来（§7.2 风险 R2）。

### 2.3 为什么 Claim A 不是已有工作的重复（这一节是评委正对着看的地方）

必须**同时**说明下面四件事，缺一条就会被打回「就是把 GUM 抄了一遍」：

1. **GUM 是通用传播律，不面向示波器测量**。
   `u = δx/√12`（量化，JCGM 100:2008 §H.5）、合成标准不确定度传播律（Eq.(10) §5.1.2）、
   `U = k·u_c`（§6.2.1，k 必须声明）、Welch–Satterthwaite 有效自由度（Annex G.4.1）——
   这些是**公式**。本项目要做的是**把这些公式接到具体测量算子上**：频率（argmax/边沿间隔均值）、
   上升时间（交叉点插值，**非线性算子**）、Vpp（min/max，**极值统计**）、占空比（±1 样点计数误差）。
   **非线性算子适用的是 JCGM 101:2008 §7.9 的自适应蒙特卡洛**，不是 GUM 的线性传播 —— 这一步是工程新增。
2. **Python 生态有通用 UQ 库，但没有接到示波器上**。`uncertainties` / `metrolopy` 能做 GUM 传播，
   `uncertainty-toolbox` / `UQpy` / `OpenTURNS` 等更成体系（**T5 于 2026-10-11 用 GitHub 检索实测存在**），
   但**在检索能力受限下未发现**任何把它们接到**示波器测量**上的实现。
   ⚠ **禁止**把这一条写成「没有不确定性库」—— 那会当场被拆。
3. **「第三个值」有标准依据，不是本项目的发明，但没人把它做成默认输出**。
   JCGM 106:2012 的**判定规则**（§3.3.12）、护带（§3.3.11）、简单接受/共担风险（§8.2）、
   护带判定规则（§8.3）、消费者/生产者风险（§9.4–9.5）给出一个关键结构：
   **当不确定度跨越判定限时，二元判定不被数据支持，正确的输出是「不确定」这第三个值。**
   本项目已有 7 个 `UncertainReason`（`signal.rs:440-455`）作为**定性**雏形，缺的是**由数值不确定度驱动**的版本。
   这一条要写在论证里而不是演示里：第三值是判定规则的输出，**没有数值不确定度它只是一句错误报告**。
4. **可验证性有模板**：arXiv:2609.28926 用「**事先锁定 6 个容差** + 专家**留出**的拟合结果打分」
   来验证 LLM agent 驱动仪器 —— 本项目可借用其**形式**（预注册容差 + 留出集），
   但**本轮的验证规模远小于它**，不得声称同等的验证强度（见 §7.6）。

**最后一条最硬的自我举证（可当场 grep 给评委看）**：
> 在本仓库（`D:\比赛\I2C\F103`）的 Rust 源码里 grep `uncertainty` —— **零命中**（§1.2 G1）。
> 也就是说：一个已经有 8 个 crate、16 个 MCP 工具、模拟器与 GUI 的项目，
> **至今没有一行不确定度代码**。这个「缺口」可复现、可当场验证，是**本项目自身的**创新空间证据。
>
> ⚠ **T5 修正**：这只证明**本项目**没有，**不证明业界没有**。
> 「比任何『业界没人做』的说法都硬」这句是**错的**——两者不是同一件事，不要把它当先例论证用。
> 先例空白只能靠 A.3/A.4 的检索结果说话，且必须带「在检索能力受限下未发现」的口径。

### 2.4 换板无关性：不确定度模型真的能自动适配吗

T1 的结论是**「成立，但『自动』要限定在三层」**。这是本方向最有说服力的一点，
因为它把「换板」从一个**叙事口号**变成一个**可计算的推论**。反向求解的边界式（T1 §5，F103 参数、k=2）：

| 边界 | 数值 | 依据/口径 |
|---|---|---|
| 最高可测频率 `f_max` | **≈138 kHz** | 0.1% 相对频差预算 |
| 最短可测脉宽 `τ_min` | **≈404 ns**（或 0.47 个采样周期） | 10% 脉宽相对误差预算 |
| 最短可测上升时间 `tr_min` | **≈1.17 µs** | 与 §7.2 的物理限制一致 |
| Vpp 的标准不确定度 | `σ_Vpp ≈ 1.3·σ_n·V_LSB`（≈1.1–1.6 mV @ σ_n = 3–5 LSB） | T1 数值实验 |

**反直觉结论（答辩抗打点，必须带出处）**：
> 抖动引入的时间不确定度 **随采样率下降而上升**，所以**换更快的板子不一定让时基更准**，
> 反而更吃前端带宽。T1 给出 `σ_t = sqrt(σ_h² + σ_off²) / v_th` 的形式。
>
> ⚠ **本文对这条式子的复核意见**：按量纲，`[σ_h] = [σ_off] = LSB`（电压），`[v_th] = LSB/s`（斜率），
> 相除得**时间**，量纲自洽。但该式只在「阈值附近斜率近似恒定」的局部线性近似下成立；
> 完备形式应为 `σ_t = σ_v / |dV/dt|_阈值`。**写作时应同时给出一般式，不要只给化简式**，否则会被问住。
> 一般式与 κ 的取值见 `docs/11` §4.4。⚠ 该处 κ 取 0.884 / 1.021，与独立推导的 1.25 不一致，
> **复核前不得进材料**（已登记于 `docs/11` §11.4）。
> 出处：T1 报告。**注**：原拟引 arXiv:2601.14881 作旁证，T1 复核判定该文是 OFDM/ISAC 采样抖动、不含本式，旁证已删除（见附录 A.2 末行）。

| **P-1** | **把占用率当置信度** | `signal.rs:67` 的注释写着「**这就是置信度**」，但占用率是**几何量**（落在平台带内的样点占比），不是**统计量**。真置信度必须由不确定度给 | 「占用率 0.95，所以这个判断有 95% 把握」 |
| **P-2** | 用 ML 分类波形 | 本项目数据量、可解释性纪律、无 FPU（`docs/00-origin.md` 四条约束表）三条都不支持；分类错了无法归因 | 「用神经网络识别波形类型」 |
| **P-3** | 报 FFT / THD / SFDR / ENOB | `docs/00-origin.md` 能力边界已把 THD/SFDR 写进「不能」列；2048 点以上 float FFT 在 F103 上做不到 | 「支持 THD 分析」 |
| **P-4** | 把测不到的边沿报成数字 | `Ts ≈ 1.167 µs`，亚微秒边沿**在数据里没有中间样点**；`measure.rs` 的 `transition_ns` 已经**如实返回 `None`** | 让演示好看而回退成「凑一个数」 |
| **P-5** | ETS（等效时间采样）当深存储 / 当「证明总线正常」 | `docs/05-roadmap.md:180` 已要求「必须标注失效场景」 | 「ETS 替代深存储」「ETS 可证明总线正常」 |
| **P-6** | TI-ADC 失配校准当卖点 | `lib.rs:88-89` 的双 ADC 交织**仅用于显示**（注释原文），不是测量通路 | 「自校准 TI-ADC 失配」 |
| **P-7** | 加一个 `uncertainty` 字段就当做过 | 字段不等于传播。`Measurements` 加一个 `f64` 谁都能加；**难的是非线性算子的传播与判定规则** | 「已实现不确定度」（未做 MC 传播 / 未做判定规则时） |

### 4.3 30 秒演示脚本

| 1 | 连设备 | `scope_connect(transport=…)` | 设备事实（采样率/位数/通道数）**从设备读回**，不是写死的 |

| 5 | 「没有真机标定数据，`u` 从哪来？」 | 第一版 `u` 只能来自模型 + 模拟器数据，真机标定项（噪声底/抖动/带宽）**全部标【推断】**，不生成无依据精度的数值（R7） |

**最可能失分的三个点**（按严重度）：

1. **作品形态口径** —— 赛题逐字要求「已完成开发的软件产品 + 完整核心功能模块 + 可安装包/在线演示」（§4.1、§7.1）。「只有模拟器可演示 + 真机未验」在这条下有实质风险，且属材料层问题，答辩技巧弥补不了；
2. **真机不可达 + 无真机标定**（G6/R5/R7）—— 演示只能靠模拟器；
3. **创新点落到 7–13 分档**（「显著改进」）—— 需要在创新点陈述里把「架构模式」立住；另外三项各 20 分才是分数大头。
