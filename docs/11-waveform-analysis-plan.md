## 3 缺陷清单

> 结构取自 T3 的 11 问逐条作答；每条给现象、触发条件、实测数据、影响范围、修复方向。
> 涉及数值冲突的条目在 §11.3 登记裁决。

### D1 边沿检测无迟滞（一级缺陷）

**现象**：中点单阈值比较（`measure.rs:223-238`：`s[i-1] < mid && s[i] >= mid`）在边沿缓慢或噪声较大时，
一次物理边沿被计成多次跃变，`edges` 与频率同时失真。同一份采集内，`edges` 与 `freq_hz` 一起变错。

**触发条件**：边沿在中点附近的每样点增量 Δ 与噪声底 σ_v 之比过小（T3 给出失效边界 S₁ = Δ/σ_v ≲ 4），
而非「平台靠近中点」【T3】。以慢边沿为主导：幅度 2867 LSB、上升沿 200 µs 时，
若 200 µs 指全摆幅则 Δ = 2867/171.4 ≈ 16.7 LSB/样点；若指 10-90% 跨度（本文探针的构造）则
全摆幅为 250 µs、Δ = 2867/214.3 ≈ 13.4 LSB/样点。两种读法都落在 S₁ ≲ 4 的失效区（σ_v = 40 LSB 时
S₁ = 0.33）。

**实测数据**：

| 来源 | 构造 | 旧读数 | 真值 |
|---|---|---|---|
| T1 记录（**按字面参数未复现**，见下） | 1 kHz 方波 + 2 µs 沿 + 5 LSB 噪声底 | **1292 Hz** | 1000 Hz |
| T1 记录（**按字面参数未复现**） | 2 kHz、5% 占空比脉冲 | **22 kHz（>10×）** | 2000 Hz |
| T1 | 1 kHz、200 µs 沿、2867 LSB | σ=40 LSB → 1249.84 Hz（+25%）；σ=160 LSB → 311688 Hz（+31069%）；沿数 10→32 | 1000 Hz |
| T3 条件 A | 1 kHz 方波、200 µs 沿、2867 LSB、4096 点、白噪声 | σ=5/10/20/40/80/160 LSB → 1079.5/1618.7/3515.3/131641.7/222528.9/233239.4 Hz | 1000 Hz |
| T3 条件 B | 1 kHz 正弦、pp=3400 LSB、20 LSB 噪声 | 3984.4 Hz（+298%） | 1000 Hz |
| **附录 A 表 A.2（本文独立复现）** | 条件 A 同族构造，3 个种子 | σ=20：1298.4/1000.2/1249.8 Hz；σ=40：2463.1/5226.5/1909.9 Hz；σ=160：173160/151260/153846 Hz | 1000 Hz |
| **附录 A 表 A.3（本文独立复现）** | 条件 B 同族构造，5 个种子 | σ=20：2331.9–3492.4 Hz | 1000 Hz |

**复现状态（必须随数字一起引用）**：

- T1 文末自行更正：**1 kHz + 2 µs 沿 + 5 LSB → 1292 Hz** 与 **2 kHz/5% → 22 kHz** 两条按字面参数
  未复现（T1 复跑得到 999.9 Hz 与 2000.1 Hz）【T1 转述纠正 ①】。
- 可复现的是同一机理，且触发条件更严：需要在边沿中点附近存在噪声（T1 的失效点约 1.4% 满量程【T1】；
  T3 的失效起点更低，σ ≥ 5 LSB 即出现偏差【T3】）。
- 本文独立复现落在 T3 一侧：σ ≤ 10 LSB 干净，σ = 20 LSB 起出现 +25%~+30% 的偏离（表 A.2）。
- 因此对外引用口径：**两条 1292 Hz / 22 kHz 标为「T1 记录，按字面条件未复现」**；
  可复现的失效数字以条件 A / 条件 B 与附录 A 为准。
- **未复现的定量原因（本文推导 + 探针复核）**：2 µs 沿在中点附近的每样点增量
  Δ = pp/(0.8·Tr/Ts) ≈ 1338 LSB（pp = 2867 LSB），Δ/σ_v = 268；而可复现的失效边界是 Δ/σ_v ≲ 4（T3）。
  要让 2 µs 沿落到该边界，需要 σ_v ≈ 334 LSB（= 8.17% 满量程），而不是「5 LSB 噪声底」；
  反之 200 µs 沿的 Δ = 13.38 LSB/样点，Δ/σ_v = 4 只需 σ_v ≈ 3.34 LSB —— 这正是条件 A 能复现的原因。
  本次核查按字面参数跑了 4 种构造 × 5 个种子（10-90% = 2 µs / 全摆幅 = 2 µs / pp = 3890 LSB /
  σ = 0 与 σ = 50），1 kHz 全部得到 1000.17 Hz；2 kHz/5% 占空比跑了 3 种构造 × 5 个种子，
  全部得到 1999.75–2000.07 Hz（附录 A 表 A.9）。

**影响范围**：`scope_measure(freq/duty/high_ns/edges)`、`report.rs:217-281` 的证据包、
GUI 测量面板（`gui/src/panels.rs:1112`）、`signal.rs:classify` 的周期与稳定性判据（同一批边沿）、
以及本方案新增的 TIE 与瞬态特征（都以边沿时间为输入）。

**修复方向**：单遍迟滞状态机（§4.1），带宽 h = min(3σ̂, 0.25·sep)，回扫取「中点首穿点」以保持索引口径。

### D2 上升/下降时间的量化地板

**现象**：10%/90% 交叉点线性插值（`measure.rs:253-346`）在边沿跨度不足若干个样点时给出受量化支配的读数。

**触发条件**：10-90% 跨度 ≲ 3 个采样周期（Ts = 1166.67 ns）。

**实测数据**：

| 10-90% 跨度 | 真值 | 实测 | 偏差 |
|---|---|---|---|
| 0.5 样点 | 583 ns | 933 ns | +60% |
| 1.0 样点 | 1604 ns（T1 记录） | — | +37% |
| ≥3 样点 | — | — | ±2 ns |

地板 ≈ 0.8·Δt ≈ 933 ns。出处【T1】。与 `report.rs:278` 的散文声明「分辨率约 1 个采样周期」一致。

**影响范围**：`rise_ns`/`fall_ns`；一切以边沿斜率为输入的派生量（压摆率、τ）。
**修复方向**：不改函数；把地板写进出口口径（拒答或标上界），并在证据包中与实测值一起给出（§4.6）。

### D3 混叠下测量出口仍给数

**现象**：`signal::classify` 会因周期过短判 `Aliased`（`signal.rs:711-715`），并把「采样密度不足」
渲染进证据包（`report.rs:439-449`）；但 `measure()` 全函数没有混叠门，`freq_hz`/`duty_pct` 照常返回
（`measure.rs:148-170`）。同一份证据包中因此可同时出现「周期仅 2.1 样点，看到的形状不代表真实波形」
与一个精确的频率数字。

**触发条件**：周期 < 3 个样点（`signal.rs:554`），或存在高于奈奎斯特的谐波（方波/振铃）。

**实测数据**：T3 对振铃频率施加混叠规则后拦截两组：400 kHz → 362.6 kHz、600 kHz → 267.9 kHz 均被拦【T3】。
本文未独立复现该两组构造（T3 的原始构造在 T3 会话回复中）。

**影响范围**：`measure.freq_hz`、`duty_pct`、以及本方案新增的振铃频率与 TIE。
**修复方向**：把混叠判据从分类器移入测量出口（§4.7），返回「只给上界」或「拒答」。

### D4 门限实现四处不同源

| # | 实现 | 位置 | 门限 | 迟滞/去抖 |
|---|---|---|---|---|
| 1 | 测量边沿 | `measure.rs:223-238` | 实测中点 (lo+hi)/2 | 无 |
| 2 | 采集摘要边沿计数 | `capture.rs:111-129` | 固定 2048 LSB | 无 |
| 3 | 形状判定 | `signal.rs:611-612`（复用 #1）、`signal.rs:160`（双电平） | 实测中点 / Otsu | 无 |
| 4 | I2C 解码 | `i2c_decode.rs:116-124`（VIL 0.3/VIH 0.7·VDD）、`:658-690`（`debounce_ns`，默认 50 ns） | 双门限 | **有**（时间型去抖） |

**现象**：同一信号在四处得到不同的跃变数（`measure.rs:76-78` 自陈 #1 与 #2 不同源；`mcp/src/params.rs:333-335`
把这个差异写进了参数说明）。GUI 的显示跨度用 #2 反推（`gui/src/vmodel.rs:191-207`），测量用 #1。
**触发条件**：信号存在直流偏置或摆幅不跨越 2048 LSB 时，#1 与 #2 必然分家；
任何同时使用测量出口与采集摘要/GUI 的场合都会遇到。
**实测数据**：`measure.rs:657-671` 的既有用例即该差异的实测记录 —— 信号在 3000..4000 LSB 之间摆动时，
实测中点口径给出 39 个跃变，而固定 2048 口径的计数器给出 0 个（该用例同时断言两者不同源）。

## 4 新增与改进能力设计

### 4.1 统一门限与迟滞状态机（P0）

**算法**：单遍状态机，两个阈值
`up = mid + h/2`、`dn = mid − h/2`，`mid = (lo + hi)/2`（实测窗内极值中点，与 `measure.rs:125` 同口径），
`h = min(3σ̂, 0.25·sep)`，`sep` 为双电平间隔（`signal.rs:109` 的 `sep_lsb`；无平台时用窗内峰峰值）。

- 状态 `LOW`：若 `s[i] >= up` → 转入 `HIGH`，上报**本段内首次穿过中点**的索引（`s[j-1] < mid <= s[j]` 的最小 `j`）。
- 状态 `HIGH`：若 `s[i] <= dn` → 转入 `LOW`，上报本段内首次下穿中点的索引。

**数学依据（本文推导）**：单阈值比较器在中点附近的抖动由每样点增量 Δ 与噪声 σ_v 的比值决定。
一次物理边沿被计成 k 次跃变的条件是瞬时值在中点附近来回穿越；引入带宽 h 后，回穿要求噪声把瞬时值
反向推开 h 的距离。取 h = 3σ_v 时，单次回穿概率的上界为 `2Q(3) = 2.7×10⁻³`，
边沿在中点带内停留 `n_mid = 2h/Δ` 个样点，故一次边沿发生回穿的概率上界为 `n_mid · 2Q(3)`：
按条件 A 的构造（Δ = 13.38 LSB/样点、200 µs 为 10-90% 跨度）σ_v = 40 LSB → n_mid = 17.9、上界 4.84%；
σ_v = 20 → 2.42%；σ_v = 5 → 0.60%（表 A.5）。
该上界是**推导值**，未做独立蒙特卡洛复核【推断】；它与附录 A 表 A.2 的观测一致：
σ_v = 40 LSB 时 3/3 个种子恢复正确读数，σ_v = 80/160 LSB 时 3 个种子中各有 1 个残留 +25%~+50%。

**为什么不是「平台靠近中点」**：分类器已用 Otsu 分离平台（`signal.rs:160`），
平台位置本身不产生假跃变；失效点是**边沿中途**的采样值在中点附近徘徊【T3】。

**算法源与改进点**：

| 来源 | URL | 本项目改了什么 |
|---|---|---|
| 硬件侧施密特迟滞状态机（同仓固件） | 本仓 `docs/05-roadmap.md:49`（`firmware/App/trigger.c`） | 主机侧原本**没有**对应实现（T1 复核：全链路 grep 无迟滞代码）；本文把同一原理搬到主机侧，并按实测噪声自标定带宽 |
| 比较器迟滞的带宽-噪声关系 | 外部定量来源未核实（见 §11.4） | 本文给出一阶概率上界（见上），不引用未经核实的定量式 |
| 单个门限的穿越判定（IEEE 181 系列） | <https://standards.ieee.org/ieee/181/4139/>（**未核实**：T1/T5 记录 403） | 保持交叉点插值定义不变，只改「跃变是否成立」的判定 |

**输入条件**：一维样点序列 `&[u16]`、实测中点、带宽 h。h = 0 时退化为原单阈值比较（回退路径）。
**输出量**：两个 `Vec<usize>`（上升/下降沿的样点索引），量纲为**样点序号**（整数，无量纲时间）。
**不可测条件下的返回口径**：`s.len() < 2` 或 `hi <= lo` 时返回空向量（与 `measure.rs:104-123` 的直流分支一致）。
**验证方法**：§8.1 用例 P0-T1..P0-T4；变异测试 M1/M2（§8.2）。

### 4.2 噪声底自标定 σ̂（P0）

**算法**：
1. 有双电平平台：取落在 `vlo ± 2%·sep` 与 `vhi ± 2%·sep` 带内的样点，计算相邻差 `Δ_i`，
   `σ̂ = MAD(Δ)/0.6745/√2`。
2. 无平台（正弦、噪声、阶跃）：退化为全样点 `MAD(Δ)/0.6745/√2`。

**数学依据（本文推导）**：白噪声差分的方差是原噪声的两倍（`Var(x_i − x_{i−1}) = 2σ²`），
故需除以 √2；高斯分布下 `MAD = 0.6745σ`（由 `P(|X−μ| ≤ 0.6745σ) = 0.5` 得出），故除以 0.6745
得到 σ 的一致估计。
`MAD` 的定义取自 NIST/SEMATECH e-Handbook §1.3.5.6（<https://www.itl.nist.gov/div898/handbook/eda/section3/eda356.htm>，
本会话 HTTP 200 已读）。选用 MAD 而非标准差的原因是该手册给出的稳健性论证——
方差/标准差对尾部敏感，MAD 基于秩、不受极端值影响（同页）。
该页的正态分布示例为 10000 点样本：标准差 0.997、MAD 0.681，比值 0.683，与 0.6745 的差异来自有限样本。

**算法源与改进点**：源同上 NIST 手册第 1.3.5.6 节（度量尺度）。
改进点：① 只在平台带内取差分，避免把边沿本身计成噪声（边沿是信号，不是噪声）；
② 无平台时退化，使自标定在全波形类型上都有定义；③ 输出直接作为 h 的输入，替代固定常数 16 LSB（§3 D5）。

**输入条件**：样点数 ≥ 16（与 `signal.rs:47` 的 `MIN_SAMPLES` 同量级）；无平台时要求峰峰值不小于
`MIN_SEP_LSB`（256 LSB，`signal.rs:54`）。
**输出量**：`σ̂`，单位 **ADC LSB**（量纲：电压，标定后为 V；不标定时为 LSB 刻度）。
**不可测条件下的返回口径**：样点不足或全平坦时返回 `None`，迟滞带宽退化为 h = 0（等价于原行为）。
**验证方法**：§8.1 用例 P0-T3（真值对照表：0/2/5/10/20/40/80/160 LSB，容差按表 A.4 现状定为 ±35% 或更严，
由实现阶段的实测决定）；变异测试 M3。

### 4.3 质量旗标与拒答门（P2）

**算法**：在 `Measurements` 出口附加一个质量判定的结果对象，字段：
`period_cv`（过滤后间隔的变异系数）、`sigma_hat_lsb`、`hysteresis_lsb`、`n_edges`、
`verdict`（枚举：`Ok` / `Refused(reason)`），其中拒答条件为
`cv > max(0.10, 0.5/mean_gap)`（与 `signal.rs:719` 同一门限口径）。

**数学依据（本文推导）**：间隔的 cv 在「有额外假跃变」时必然升高：假跃变产生额外的短间隔，
而中位数×1.5 的过滤器（`measure.rs:390-407`）只丢弃**长**间隔，不丢弃短间隔，
于是短间隔进入均值与 cv。因此「cv 异常」是「边沿集合被污染」的可观测量，
两者由同一批数据导出，不需要额外假设。

**算法源与改进点**：

| 来源 | URL | 改进点 |
|---|---|---|
| 本仓既有 cv 口径 | `signal.rs:542`（`MAX_GAP_CV`）、`signal.rs:719`（量化感知门限） | 原本只用于**分类**（`Unknown(IntervalUnstable)`）；本方案把它并入**测量出口**，使数值与「是否有资格给数」同时可见 |
| ngscopeclient 的测量出口形态（对照） | <https://www.ngscopeclient.org/manual/contentsname.html>（本会话 HTTP 200；26.110 Jitter、26.27 Clock Jitter (TIE)） | 在检索能力受限下未发现其测量结果带「可信/不可信」字段；本方案以**带原因的拒答**而非缺省值表达 |

**输入条件**：`measure()` 可运行的一切输入；沿数 < 3 时 `filter_gaps` 返回 `None`（`measure.rs:391-393`），
对应拒答原因 `TooFewEdges`。
**输出量**：无单位的比值（cv）与 LSB 刻度（σ̂、h）以及枚举判定；**不含时间量**。
**不可测条件下的返回口径**：任何可用 cv 判定为污染的采集，返回 `Refused`，且 `freq_hz` 等既有字段
保持既有 `Option` 语义（`None`），不改为 0。
**验证方法**：§8.1 用例 P2-T1/T2（真值 1000 Hz，判定「既错又给数」的行数必须为 0）；
本文独立复现该指标：24 行构造中「既错又给数」= 0/24（表 A.2、A.6）。

### 4.4 单次采集内 TIE 与周期抖动（P3）

**算法（六步）**：

1. **门限与噪声底**：§4.1 + §4.2。
2. **边沿索引**：迟滞状态机输出同向边沿索引 `i_k`。
3. **亚样点边沿时刻（线性插值）**：`t_k = (i_k − 1 + frac_k)·Ts`，
   `frac_k = (mid − s[i_k−1])/(s[i_k] − s[i_k−1])`，`Ts = 1/rate_hz`。与 `measure.rs:310-323` 的
   交叉点插值同一形式。
4. **理想格点**：沿用 `filter_gaps` 的过滤口径（`measure.rs:390-407`：中位数 × 1.5 筛选），
   在**插值后的间隔**上做同一筛选，`T̂ = mean(kept)`（`measure.rs:140-147` 的同一取法）。
5. **TIE 序列**：`TIE_k = t_k − (t_0 + k·T̂)`；周期抖动序列：`P_k = t_k − t_{k−1} − T̂`。
6. **统计量**：`σ_TIE`（样本标准差，n−1 分母）、峰峰值、均值、样本数 n；
   σ 的置信区间用卡方：`[(n−1)s²/χ²_{1−α/2,n−1}, (n−1)s²/χ²_{α/2,n−1}]`，α = 0.05；
   直方图箱数用 Freedman–Diaconis 规则 `k = ⌈(max−min)/h⌉`，`h_FD = 2·IQR·n^{−1/3}`。

**数学依据（本文推导 + 蒙特卡洛核验）**：

- **整数样点法的地板**：边缘时刻误差 `e ~ U(−Ts/2, Ts/2)`，`σ_e = Ts/√12`。
  Ts = 1166.67 ns 时 **σ_e = 336.79 ns**（表 A.7），与 T1 实测的「单沿跨越分辨率 336.8 ns RMS」一致【T1】。
  单个间隔由两个独立边沿相减，`σ_gap = Ts/√6 = 476.29 ns`；T1 的 100 kHz 构造含 478 个同向沿
  （即 477 个间隔），其均值 SEM 下界为 `476.29/√477 = 21.81 ns`（T1 实测 26.44 ns，
  差值由真实抖动与非白噪声成分解释）。
- **插值法的不确定度**：阈值穿越时刻的一阶传播为 `σ_t = σ_v/|dV/dt|`（阈值处斜率倒数，量纲 s）。
  对 10-90% 跨度为 `Tr`、峰峰为 `pp` 的边沿，`|dV/dt| = 0.8·pp/Tr`，故 `σ_t = κ·(σ_v/pp)·Tr`。
  本文用两点线性插值误差传播与蒙特卡洛（每组 2 万次，ρ = Tr/Ts 从 0.343 到 171.4）得到
  **κ = 0.884**（穿越点恰在采样间隔中点）到 **κ = 1.021**（相位均匀时的平均），
  核验比值 1.016–1.028（表 A.7）。T2 的拟合值 0.884 即前者【T2】；相位平均下应取 1.021。
- **改善倍数**：Tr = 2.5 µs、σ_v = 2 LSB、pp = 3600 LSB 时，
  κ = 0.884 → 1.228 ns，κ = 1.021 → 1.417 ns，相对整数法的 336.79 ns 改善 **237×**；
  σ_v = 5 LSB 时为 95×（表 A.7）。T2 记录的 ≥90× 对应后者【T2】；对外引用取 ≥90×。

**算法源与改进点**：

| 来源 | URL | 改进点 |
|---|---|---|
| TIE 的 ngscopeclient 实现（对照） | <https://www.ngscopeclient.org/manual/Filters.html#clock-jitter-tie>（章节号经 `contentsname.html` 复核；正文因长页截断未逐字读取） | 其 TIE 与时钟恢复（26.29 PLL）的关系为【T1 记录】，其手册正文未由本文独立读取。本方案不引入 PLL：以整段采集的均值格点 T̂ 作为参考，避免未锁相时的拍频伪抖动【T1】 |
| 交叉点线性插值（脉冲测量定义） | <https://standards.ieee.org/ieee/181/4139/>（**未核实**，403） | 同一插值形式，从「单次上升时间」扩展到「逐沿时刻序列」 |
| 卡方区间、FD 直方图 | χ² 区间为标准统计结论（本文推导）；FD 规则为命名启发式，出处 <https://www.jstor.org/stable/2322619>（**未核实**：本会话未抓取） | 无修改，按标准式引用 |

**输入条件（硬性）**：

- 同向边沿数 `n ≥ N_min`；本文建议 `N_min = 30`（σ 的相对不确定度约 `1/√(2(n−1))`，n = 30 时约 13%）。
  该建议值为本文给出【推断】，T2 未给 N_min 数值。
- 边沿跨度与采样周期之比 `ρ = Tr/Ts ≥ 2`（T2 的适用区间）【T2】。
  本仓场景的 ρ：`pwm_1k_25` / `pwm_1k_75` / `pwm_1k_5` 的 10-90% 为 4 µs → ρ ≈ 3.43（可用，
  `sim/src/waveform.rs:655`、`:660-678`）；`square_50k` 的全摆幅为 400 ns、10-90% 为 320 ns → ρ ≈ 0.27
  （落在拒答区，`sim/src/waveform.rs:319-329`）。
- 采集内无混叠告警（§4.7），间隔 cv 通过拒答门（§4.3）。

**输出量**：`n_edges`（个）、`sigma_tie_ns`（ns）、`pk_pk_ns`（ns）、`mean_tie_ns`（ns）、
`ci95_low/high_ns`（ns）、`resolution_floor_ns`（ns，本次条件下由 σ_v、pp、Tr 算出的单沿不确定度）、
`method`（枚举）、`verdict`。全部为时间量，量纲 s，输出单位 ns。
**不可测条件下的返回口径**：

- `ρ < 2` 且 `ρ ≥ ρ_min`：返回值但附 `grid_limited` 标记；
- `ρ ≤ 0.35`：返回 `Refused(EdgeTooFastForTie)`（T2 的栅格拒答门【T2】；该门限的依据见 §11.3 冲突 3）；
- `n < N_min`：返回 `Refused(TooFewEdges)`；
- 存在混叠告警：`Refused(Aliased)`；
- 数据非平稳（漂移门，见 §4.8）：`Refused(NonStationary)`。

**验证方法**：§8.1 用例 P3-T1..P3-T4；原型核验用 `pwm_1k_25` / `pwm_1k_75`（10-90% 为 4 µs → ρ ≈ 3.43）
与 `pwm_1k_5`（窄脉冲，ρ 同量级）；期望值由 `σ_t = κ·(σ_v/pp)·Tr` 推导，κ 取 1.021。
`square_50k`（ρ ≈ 0.27）用作拒答路径的核验场景，不作为报数场景。

### 4.5 逐沿趋势输出（P1）

**算法**：输出边沿时刻序列的**趋势量**，而不是原始数组：按序号分桶（桶数取 8，或按 `n/8` 取整），
每桶给出 `mean_gap`、`cv`、`min_gap`、`max_gap`；附全段 `drift`（沿用 `signal.rs:617-624` 的前后半段差定义）。

**数学依据（本文推导）**：漂移与抖动的分离条件是时间尺度。把 n 个间隔按序号连续分桶，
桶内均值对慢漂移敏感、对零均值抖动不敏感（桶内均值的抖动被平均降低 √(n/8) 倍）；
前后半段差是桶数为 2 的特例，现有 `drift` 已是该族最简单成员（`signal.rs:506-508`）。

**算法源与改进点**：源自 ngscopeclient 的「每个周期输出一个样本」的做法
（手册 26.9 AC RMS 的 `trend` 输出口：每周期一个样本；<https://www.ngscopeclient.org/manual/Filters.html>）。
改进点：不返回逐周期序列，而返回**分桶统计**，原因是本项目出口是文本证据包与 MCP 返回值，
逐周期序列会挤占 `MAX_CHARS`（`report.rs:61`）与 token 预算。

**输入条件**：同向边沿 ≥ 3（`measure.rs:391`）。
**输出量**：`bucket_count`（个）、每桶 `mean_gap_ns`（ns）、`cv`（无量纲）、`min/max_gap_ns`（ns）、
`drift`（无量纲，相对值）。
**不可测条件下的返回口径**：间隔数 < 2·桶数 时降低桶数；间隔数 < 3 时整个趋势字段为 `None`。
**验证方法**：§8.1 用例 P1-T1（合成线性扫频：漂移可解析计算）；变异测试 M5。

### 4.6 瞬态特征（P1）

### 4.7 混叠拒答规则（P1）

**算法**：对频率类新量（振铃频率、TIE 的格点频率、以及 `measure.freq_hz` 的出口）施加采样密度门：

| 半周期样点数 | 输出 | 依据 |
|---|---|---|
| ≥ 4 | 报数 | 每周期 ≥ 8 样点，前两次谐波在奈奎斯特以内 |
| 2 ≤ x < 4 | 只给上界 `f ≤ rate/8` | 形状不可验证，频率仍可给区间 |
| < 2 | `Refused(Aliased)` | 与 `signal.rs:554` 的 `MIN_PERIOD_SAMPLES = 3` 同族 |

**数学依据（本文推导）**：以速率 Fs 采样的实信号，其可分辨的频率上限为 Fs/2；要在**波形形状**上
区分基波与谐波混叠，需要在半周期内取得足够样点以重建形状。半周期 4 样点对应每周期 8 样点，
即基波与二次谐波均在奈奎斯特以内（`Fs/8 < Fs/2`）。
**算法源与改进点**：源为本仓既有 `MIN_PERIOD_SAMPLES`（`signal.rs:549-554`）与 `UncertainReason::Aliased`
（`signal.rs:451-452`）；改进点是把该判据从分类器移入测量出口，使「分类说不知道、测量照给数」的矛盾消失
（§3 D3）。外部对照：ngscopeclient 手册的 `Squelch`（26.167）、`Threshold`（26.178）为门控块
（<https://www.ngscopeclient.org/manual/Filters.html>，本会话 HTTP 200，章节存在性经目录页复核），
但本方案不引用其参数作为依据 —— 该页 26.167/26.178 的正文未逐字读取。
**输入条件**：可测的周期估计。
**输出量**：频率（Hz）或上界（Hz）或拒答枚举。
**不可测条件下的返回口径**：见上表；拒答不返回数值。
**验证方法**：§8.1 用例 P1-T4（`RingAlias` 场景）；变异测试 M6。

### 4.8 跨采集累积统计（P4，条件性）

**算法**：对同一设备、同一配置下的多次采集，按下列顺序合并：
① 对每次采集独立求 σ̂、边沿索引、插值边沿时刻与 T̂_j；
② 非平稳门：相邻采集的 `T̂_j` 相对差 < 0.1% 且 σ̂_j 相对差 < 30%，否则拒绝合并（阈值待定，见 §10 Q3）；
③ 合并方式：把各次的 TIE 序列按**各自 T̂_j**归一后拼接，输出合并的 σ、直方图与 CI。

**数学依据（本文推导）**：n 次独立采集把样本数提高 n 倍，σ 的相对不确定度按 `1/√(2(n−1))` 下降，
即 CI 宽度收窄约 √n 倍。合并前必须做非平稳检验，因为时钟漂移与温漂在采集之间表现为**低频**偏差，
会被误计为抖动（同类误差在 ngscopeclient 的 TIE 模块中有记载：PLL 未锁定时因拍频报出极大抖动，
仅靠手工 `Skip Start` 缓解【T1】）。

**算法源与改进点**：源为 ngscopeclient 手册 26.15 Average（多波形平均）、26.93 Histogram
（<https://www.ngscopeclient.org/manual/contentsname.html>，本会话 HTTP 200 复核章节存在）。
改进点：本项目不引入滤波器图，改为在**采集仓**（`core/src/capture.rs:315-367`）与 MCP 会话
（`mcp/src/session.rs:50`）层面对已存采集做统计，不改变单次采集的语义。

**输入条件**：同一会话内 ≥ 2 次采集，且两次之间设备未换、采样率未变。
**输出量**：合并样本数 n、σ、pk-pk、CI、直方图箱计数、非平稳门判定结果。
**不可测条件下的返回口径**：非平稳门不通过 → `Refused(NonStationary)`；
合并后 n 仍 < N_min → `Refused(TooFewEdges)`。
**验证方法**：§8.1 用例 P4-T1（同一模拟器场景重复 N 次：σ 的估计应随 n 下降，且非平稳门下
拒绝合并「换场景后」的采集）。
**成本与优先级**：T1 估算 1.0–1.5 人天【T1】。该阶段为条件性：若不采纳（§10 Q3），§4.4 的适用信号
被限制为「单次采集内同向边沿 ≥ 30」的信号，即 Fs/30 ≈ 28.6 kHz 以上的周期信号。

### 9.2 精度的物理上限（与能力无关的硬边界）

- 时间量分辨率下界：整数边沿法 `Ts/√12 = 336.79 ns`（表 A.7）；插值法受 `σ_v/|dV/dt|` 支配。
- 幅度量：min/max 为极值统计，噪声会抬高 `max`、压低 `min`；本文不改该口径，新增量的参考电平沿用
  `signal.rs:160` 的平台均值（`measure.rs:183-195` 的同一约定）。
- 4096 点的窗内边沿数上限：`rate/(2·f)` —— 1 kHz 约 5 个同向边沿（表 A.2），25 kHz 约 123 个，
  100 kHz 约 478 个（T1 实测数【T1】）。
